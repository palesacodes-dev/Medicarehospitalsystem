# Medicare Hospital Patient Admission System

A Java-based Hospital Admission and Bed Management System built using Object-Oriented Programming, featuring interactive ward layouts and full JUnit unit test coverage.

## Overview

This project models a hospital's patient admission and bed allocation workflow. It was built to explore clean OOP design, encapsulation, class hierarchies, and separation of concerns  applied to a real operational problem rather than a toy example.

## Features
Patient admission —register new patients and assign them to available beds

Ward and bed management — interactive layout tracking bed occupancy across wards

Discharge handling — free up beds and update records on patient discharge

Unit tested — full JUnit test suite covering core logic (admission, bed assignment, discharge)

## Tech Stack
Java — core application logic, OOP design

JUnit — unit testing

## What I Learned

Building this project helped me practice designing class hierarchies for a real world domain, writing testable code, and thinking through edge cases (e.g. what happens when no beds are available) rather than just getting the "happy path" working.
